차량 보안 전 생애주기 (ISO/SAE 21434) — 위협분석(TARA) → 보안설계(Secure Boot · HSM · SecOC · MCU Secure Library) → 검증(침투·퍼징) → 산출물(CSMS · UN R155/R156 대응)
기능안전(ISO 26262)과 사이버보안(ISO 21434)을 병행(safety + security co-engineering)하고, SBOM으로 공급망 보안 리스크를 관리하도록 설계합니다.
