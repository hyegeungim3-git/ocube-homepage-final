BUSINESS · CYBER SECURITY

규제가 요구하는 차량 보안을, 양산 코드로 구현합니다

ISO/SAE 21434와 UNECE R155가 요구하는 위협 분석(TARA)부터 보안 라이브러리 구현, 기능 검증, 인증 산출물까지 하나의 흐름으로 수행합니다. 전장 소프트웨어를 양산해 온 팀이 보안을 맡기 때문에, 보안 기능이 실제 제어기 위에서 동작하도록 포팅하고 최적화합니다.

  • 대응 표준ISO/SAE 21434 · UNECE R155 · CSMS
  • 수행 범위위협분석 → 설계 → 구현 → 검증 → 인증 대응
  • 보안 협업2021~2025년 10건 수행

Core Capabilities

보안만 하지 않고, 전장 소프트웨어와 함께 다룹니다

보안 기능은 제어기 소프트웨어 위에서 동작합니다. 통신·진단·업데이트를 직접 개발해 온 팀이 보안을 맡을 때 포팅과 검증이 실제로 끝까지 갑니다.

Security Architecture

외부와 맞닿는 곳에 보안을 모으고, 말단은 가볍게 갑니다

모든 모듈에 같은 무게의 보안을 넣으면 원가와 성능이 함께 무너집니다. 외부 연결을 담당하는 통신·게이트웨이 모듈에 무거운 보안을 집중하고, 말단 모듈에는 공통 경량 계층을 동일하게 배치하는 구조를 제안합니다.

앵커 · 통신 & 게이트웨이 모듈무거운 보안 집중경계 방어·TLS · 신뢰 기점(Root of Trust)·키 관리 · 보안 업데이트 조율 · 디지털키 인증·권한관리 · 내부망 필터링 · 침입탐지 관제 연동
