What We Do

AX · AI Transformation

AI를 적용할 업무를 정하고, AI의 판단이 실제 현장 조치로 이어지게 만듭니다.
데이터 진단부터 구축과 운영까지 여섯 단계로 나눠 수행합니다.

01

AI 기회 발굴 · 데이터 진단

AI 적용 가치가 큰 업무를 선별하고, 실제 학습에 사용할 데이터가 있는지 확인합니다.

  • 적용 후보 선정 반복 판단과 대기가 많은 업무를 찾아 기대 효과와 난이도로 우선순위 결정
  • 데이터 진단 설비·업무 시스템 데이터의 품질과 라벨로 학습 가능성 판정
  • 데이터 수집 산업 통신 규격(OPC-UA·Modbus·MQTT)으로 설비를 연결하고 현장에서 데이터를 정리해 학습 자료 확보
02

데이터 표준화 · 지식화

설비·문서·이벤트 데이터를 같은 의미 체계로 정리해 모델과 에이전트가 함께 쓰는 지식 기반을 만듭니다.

  • 공통 데이터 형식 설비마다 다른 이름과 코드를 통일하고, 산업 용어·관계 체계(온톨로지)로 데이터 사이의 관계 정의
  • 문서·이미지 연결 문서·도면·이미지를 의미 기반으로 검색하고 데이터 사이의 관계까지 확인할 수 있게 구성
  • 공통 의미 체계 시계열·이벤트·텍스트를 하나로 묶어 모델과 에이전트가 함께 참조
03

AI 모델링 · 학습

과제·보안·운영 조건에 맞는 모델을 비교해 정확도와 오탐 비용을 함께 고려한 구성을 선정합니다.

  • 과제별 모델 이상탐지·예지보전·수요예측은 시계열 모델, 문서 이해는 생성형 AI·근거 검색(RAG)
  • 모델 조합 사내 데이터로 미세조정한 소형 언어모델(sLLM)과 상용 LLM API를 보안 요건에 맞춰 배치
  • 선정 기준 실험 추적·교차 검증에 더해 현장의 오탐 비용까지 반영
04

현장 검증 · 사람 확인

현장 검증으로 성과를 확인하고, 사람의 검토·승인을 거쳐 자율화 범위를 정합니다.

  • 효과 정량화 실제 현장 데이터로 도입 전후를 같은 기준으로 비교(PoC)
  • 사람 검토(HITL) AI 판단의 근거를 확인하고 애매한 사례는 다음 학습 데이터에 반영
  • 임계값 합의 오탐·미탐 비용을 현장과 맞춰 알람 기준과 자율화 수준 조정
05

AI 에이전트 · 시스템 연결

AI를 MES·ERP·설비에 연결해 분석 결과가 보고·승인·조치로 이어지도록 구현합니다.

  • 업무 연결 조회·분석·보고는 자연어 에이전트, 설비 이상은 탐지 → 제안 → 승인 → 실행 → 확인
  • 배포 방식 선택 클라우드·사내 구축형(온프레미스)·폐쇄망 중 보안 요건에 맞는 방식으로 구축
  • 업무 시스템 연동 생산관리(MES)·전사자원관리(ERP)·그룹웨어와 API로 연결해 실제 업무 흐름 안에서 작동
06

운영 · 지속 학습

모델 운영 체계를 갖춰 품질 저하에 대응합니다.

  • 데이터·성능 변화 감시 입력 데이터의 변화와 성능 저하를 찾아 재학습 검토 시점 알림
  • 버전·복구 모델 버전과 배포 이력을 관리하고, 문제가 생기면 검증된 이전 버전으로 복구
  • 지속 개선 현장 피드백과 새 데이터를 재학습에 반영해 성능 점검
