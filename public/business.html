What We Do

AX · AI Transformation

흩어진 산업 데이터를 판단으로, 판단을 실행으로 바꾸는 AI 전환입니다. 데이터 진단·표준화부터 검증된 AI 모델링, 시스템 통합과 자율 운영까지 — 현장의 일하는 방식을 바꾸는 전 과정을 6단계로 설계합니다.

AX 역량 자세히 →
01

AI 기회 발굴 · 데이터 진단

어떤 업무가 AI로 바뀔 수 있는지부터 찾습니다. 데이터가 말해주는 것과 현장이 원하는 것을 잇습니다.

  • 반복 판단과 대기가 몰린 업무를 찾아 AI 적용 기회 맵을 만들고, 기대 효과와 난이도로 우선순위를 정합니다
  • 설비 PLC·SCADA부터 MES·ERP까지 보유 데이터의 가용성·품질·라벨 유무를 진단해 학습 가능성을 판정합니다
  • OPC-UA·Modbus·MQTT 커넥터와 엣지 전처리로 모델 학습에 쓸 원천 데이터 파이프라인을 확보합니다
02

데이터 표준화 · 지식화

AI가 이해할 수 있는 형태로 — 흩어진 데이터에 온톨로지로 의미를 부여합니다.

  • 설비마다 다른 태그와 코드를 표준 스키마로 정규화하고, 온톨로지로 개체·속성·관계를 정의합니다
  • 문서·도면·이미지 같은 비정형 자료는 임베딩·벡터DB로, 개체 간 관계는 지식그래프로 연결합니다
  • 시계열·이벤트·텍스트를 하나의 의미 체계로 묶어 이후 모든 모델과 에이전트가 공유하는 지식 기반을 만듭니다
03

AI 모델링 · 학습

과제에 맞는 AI를 고릅니다. 예측이 필요한 곳엔 예측 모델을, 언어가 필요한 곳엔 언어 모델을.

  • 이상탐지·예지보전·수요예측은 시계열 특화 모델로, 문서 이해·질의응답은 생성형 AI와 RAG로 설계합니다
  • 도메인 데이터로 미세조정한 sLLM과 상용 LLM API를 과제 특성과 보안 요건에 맞춰 조합합니다
  • 실험 추적과 교차 검증으로 후보 모델을 비교하고, 정확도만이 아니라 현장의 오탐 비용까지 반영해 선정합니다
04

현장 검증 PoC · HITL

AI의 판단을 현장 전문가가 검증합니다. 신뢰가 쌓인 만큼만 맡깁니다.

  • 실제 현장 데이터로 PoC를 수행해 도입 전후 효과를 같은 기준으로 비교하고 정량화합니다
  • 사람이 승인·수정하는 HITL 루프를 설계해 AI 판단의 근거를 확인하고, 경계 사례를 학습 데이터로 되돌립니다
  • 오탐과 미탐의 비용을 현장과 합의해 알람 임계값과 자율화 수준을 조정합니다
05

AI 에이전트 · 시스템 연결

판단을 실행으로 — AI를 현장 시스템에 심고 행동으로 잇습니다.

  • 조회·분석·보고 업무는 자연어 에이전트로, 설비 이상은 탐지→조치 제안→승인→실행의 폐루프로 연결합니다
  • 클라우드·온프레미스·폐쇄망까지, 보안 요건에 맞는 형태로 모델과 에이전트를 배포합니다
  • MES·ERP·그룹웨어 같은 기간계와 API로 연동해 AI가 실제 업무 흐름 안에서 동작하게 합니다
06

MLOps 운영 · 지속 학습

도입이 끝이 아니라 시작입니다. AI는 운영하면서 더 정확해집니다.

  • 입력 데이터의 분포 변화(드리프트)와 성능 저하를 감시해 재학습 시점을 자동으로 판단합니다
  • 모델 레지스트리로 버전과 배포 이력을 관리하고, 문제가 생기면 이전 버전으로 즉시 롤백합니다
  • 현장 피드백과 새 데이터를 재학습 파이프라인으로 되돌려 모델 정확도를 유지·개선합니다
What We Do

Embedded

자동차 안에서 완성되는 양산 소프트웨어를 만듭니다. 글로벌 완성차 규격의 고신뢰 임베디드 SW를 요구·설계부터 양산까지 6단계 V-model로 개발·검증합니다.

임베디드 역량 자세히 →
01

요구 분석 · 시스템 설계

양산에서 역산합니다 — V-model의 왼쪽, 검증 가능한 설계부터.

  • 차량·디바이스의 기능 요구와 안전 요구(HARA·ASIL)를 분리해 추적 가능한 요구사항으로 정의합니다
  • HW 제약(메모리·전력·발열)을 반영한 SW 아키텍처를 설계하고, 단계별 검증 계획을 함께 수립합니다
  • AUTOSAR Classic/Adaptive 등 표준 아키텍처 적용 여부를 프로젝트 특성에 맞춰 결정합니다
02

보드 브링업 · BSP 포팅

보드에 처음 불을 켜는 일 — HW와 SW가 만나는 최하층을 책임집니다.

  • 부트로더·커널·디바이스 드라이버를 타깃 보드에 포팅하고 주변장치를 하나씩 검증합니다
  • Yocto 기반 BSP를 구성해 누가 빌드해도 같은 결과가 나오는 재현 가능한 빌드 체계를 만듭니다
  • 초기 부팅 시간과 메모리 사용량을 측정해 양산 목표치를 조기에 설정합니다
03

OS · 플랫폼 구성

Linux · QNX · Android Automotive — 용도에 맞는 플랫폼을 구성합니다.

  • 실시간성이 필요한 영역은 QNX·RTOS로, 앱 생태계가 필요한 영역은 Linux·AAOS로 설계합니다
  • 컨테이너·하이퍼바이저 기반 도메인 분리로 안전 기능과 인포테인먼트를 격리합니다
  • OTA 업데이트를 전제로 A/B 파티션과 실패 시 자동 복구 체계를 구성합니다
04

HMI · 미들웨어 개발

운전자가 만나는 화면과, 그 아래를 흐르는 통신까지.

  • Qt·QML 기반 차량용 HMI를 프레임 드랍 없는 응답성 기준으로 개발합니다
  • SOME/IP·CAN·차량 이더넷 등 차량 네트워크 미들웨어를 개발·통합합니다
  • 내비게이션·미디어·공조 등 도메인 앱과 서비스 계층을 구현합니다
05

통합 검증 · 기능안전

표준이 요구하는 만큼, 그리고 그 이상으로 검증합니다.

  • HIL 시뮬레이션과 실차 테스트로 요구사항 커버리지를 검증합니다
  • ISO 26262 기능안전과 ISO 21434 사이버보안(TARA) 프로세스를 적용합니다
  • MISRA C 정적분석·단위·통합 테스트를 CI에 연결해 회귀 결함을 차단합니다
06

최적화 · 양산 대응

마지막 1초, 마지막 1MB까지 — 양산 품질로 다듬습니다.

  • 부팅 시간·응답 지연·메모리를 프로파일링해 목표 스펙까지 최적화합니다
  • 양산 라인의 플래싱·검사 체계와 UDS 진단 프로토콜을 지원합니다
  • UN R156 SW 업데이트 규정 대응과 양산 이후 유지보수 체계까지 구축합니다
What We Do

SI · System Integration

복잡한 서비스와 업무를 하나의 시스템으로 연결합니다. 사용자 서비스부터 관리자·기존 업무 시스템까지, 안정적인 Web·App·Cloud 환경으로 6단계에 걸쳐 구축·운영합니다.

SI 역량 자세히 →
01

요구 정의 · 업무 분석

시스템이 아니라 업무를 먼저 이해합니다.

  • 현업 인터뷰와 AS-IS 분석으로 업무 흐름·병목·예외 케이스를 문서화합니다
  • 기능 요구와 비기능 요구(성능·보안·가용성)를 측정 가능한 기준으로 정의합니다
  • WBS와 마일스톤으로 일정과 리스크를 투명하게 관리합니다
02

아키텍처 · UX 설계

10년 운영을 견딜 구조와, 설명 없이도 쓰이는 화면.

  • 트래픽·데이터 규모에 맞춰 모놀리식과 MSA를 판단하고 확장 경로를 설계합니다
  • IA·와이어프레임·프로토타입으로 화면 흐름을 개발 전에 검증합니다
  • KWCAG 접근성과 반응형 대응을 설계 단계부터 반영합니다
03

데이터 · 시스템 설계

데이터가 곧 자산입니다 — 스키마부터 연동까지 정합성 있게.

  • ERD와 데이터 사전을 표준화하고 기존 데이터의 이행 전략을 수립합니다
  • 레거시·외부 시스템과의 인터페이스를 API 명세로 확정합니다
  • 백업·이중화·재해복구(DR) 체계를 아키텍처에 포함해 설계합니다
04

개발 · 통합

코드 리뷰와 CI/CD 위에서, 매주 동작하는 소프트웨어로 보여드립니다.

  • 코딩 표준·코드 리뷰·정적분석을 CI 파이프라인에 내장합니다
  • 단위·통합 테스트 자동화로 회귀 결함을 조기에 차단합니다
  • 스프린트 단위로 동작하는 결과물을 시연하며 현업과 방향을 맞춥니다
05

품질 · 보안 검증

오픈 전에 미리 다 겪어봅니다 — 성능도, 침투도.

  • 시나리오·부하 테스트로 목표 성능(응답시간·동시접속)을 실증합니다
  • OWASP Top 10 기준 보안 점검과 취약점 조치를 수행합니다
  • 사용자 수용 테스트(UAT)로 현업 승인을 받고 오픈 조건을 확정합니다
06

이행 · 운영 · SLA

오픈은 하루, 운영은 10년 — 무중단으로 넘기고, 책임지고 지킵니다.

  • 데이터 이행 리허설과 롤백 계획으로 무중단 오픈을 준비합니다
  • 모니터링·알림 체계와 장애 대응 프로세스(SLA)를 가동합니다
  • 운영 데이터 기반 개선 백로그로 시스템을 지속 고도화합니다
