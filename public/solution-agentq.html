QAgent

문서·음성·데이터베이스를 다루는 전문 에이전트가 업무를 나눠 맡고 중간 결과를 이어받아 검토 가능한 문서와 실행안까지 완성합니다.

개요핵심 기능처리 흐름업무 흐름적합한 곳
Overview

한 번의 요청을 여러 전문 에이전트가 이어받아 결과물까지 완성합니다

업무 포털에 요청하면 필요한 전문 에이전트가 문서·지식·데이터를 이어서 처리해 반복 가능한 AI 업무 흐름을 만듭니다.

전문 에이전트 허브지식검색·OCR·DB조회·분석·번역·보고서·규정검토 등 업무별 에이전트를 한곳에서 사용
멀티 에이전트 오케스트레이션앞 단계의 결과를 다음 에이전트에 자동 전달해 여러 단계의 업무를 끝까지 처리
근거·보안 중심 처리DRM·OCR 전처리, RAG 출처, 권한·보안 등급, 결과 검증을 업무 흐름에 포함
검토 가능한 결과물답변에 그치지 않고 보고서·회의록·검토서·분석 결과처럼 실제 업무에 쓰는 산출물로 완성
Features

업무마다 알맞은 전문 에이전트를 바로 연결합니다

지식 검색·문서 작성·음성 기록·규정 검토·데이터 조회·보안 채팅을 하나의 플랫폼에서 제공합니다.

RAG Knowledge Search

근거 기반 지식 검색

사내 문서와 업무 규정을 자연어로 검색하고, 답변에 사용한 근거와 출처를 함께 확인합니다.

  • 자연어·의미 검색 표현이 달라도 의미가 가까운 문서와 조항을 탐색
  • 근거·출처 확인 답변과 함께 원문 위치와 관련 문서를 제시
  • 검색 범위 적용 업무 영역과 문서 보안 등급에 맞는 자료만 조회
Standard Report

표준 양식 보고서 작성

핵심 내용만 입력하면 조직에서 사용하는 양식에 맞춰 보고서 초안을 만들고 검토할 수 있게 정리합니다.

  • 양식 선택 주간 실적·업무 조사·시황 등 업무별 표준 서식 제공
  • 정보 자동 구성 입력한 실적·일정·계획을 보고서 항목에 맞춰 배치
  • 초안 검토 생성 내용을 확인하고 수정한 뒤 공식 문서로 활용
Meeting Intelligence

음성 기반 회의록 작성

회의 녹음과 참고 자료를 올리면 발언 내용을 구분하고 핵심 논의와 후속 업무를 회의록으로 정리합니다.

  • 음성 인식 STT와 화자 분리로 참석자별 발언 내용을 텍스트로 변환
  • 내용 요약 주요 안건·결정 사항·담당 업무와 일정을 구분해 정리
  • 회의록 완성 첨부 자료를 반영해 조직의 표준 회의록 양식으로 작성
Document Review

내규 기반 문서 사전 검토

기안문과 보고서를 사내 규정·업무 지침과 자동으로 대조해 위반 가능성과 보완할 내용을 미리 확인합니다.

  • 문서 전처리 PDF·DOCX·HWP와 스캔 문서의 내용을 읽을 수 있게 변환
  • 규정 자동 대조 선택한 내규와 업무 지침에서 관련 조항을 찾아 비교
  • 검토 결과 분류 위반 가능성과 보완 항목을 심각도와 근거별로 정리
Text2SQL Analytics

자연어 데이터 조회·분석

전문적인 SQL을 몰라도 업무 질문을 입력하면 필요한 데이터를 조회하고 결과를 표와 차트로 보여줍니다.

  • 질문 자동 해석 자연어 요청에서 조회 대상과 조건을 파악해 SQL로 변환
  • 권한 기반 조회 사용자가 접근할 수 있는 데이터베이스와 항목만 검색
  • 결과 시각화 조회 결과와 조건을 표·차트·요약 설명으로 제공
Secure LLM Chat

로컬 LLM 기반 보안 채팅

민감한 질문과 문서를 외부로 보내지 않고 내부망의 로컬 LLM에서만 처리해 안전하게 대화합니다.

  • 대화 내용 무저장 질문과 답변을 서버에 남기지 않는 독립 세션으로 처리
  • 외부망 연결 차단 모든 추론과 문서 처리를 내부망 로컬 LLM에서 수행
  • AI 학습 미활용 입력한 대화와 참조 문서를 모델 학습 데이터로 사용하지 않음
처리 흐름 자세히 →
Runtime Pipeline

입력 자료가 검토 가능한 결과물이 되는 흐름

문서와 데이터를 먼저 정리하고, 근거 검색·추론·검증을 거쳐 문서·승인·내보내기로 마무리합니다.

STEP 1

업무 입력

텍스트·음성·문서·스프레드시트와 데이터 조회 요청을 접수

STEP 2

DRM·OCR 전처리

보호 문서와 스캔 파일을 해제·인식하고 검색 가능한 형태로 정리

STEP 3

RAG 지식검색

권한 범위의 문서·규정·벡터 DB에서 관련 근거와 출처를 탐색

STEP 4

sLLM 추론

사내 언어모델이 업무 목적에 맞게 요약·분석하고 다음 에이전트에 결과를 전달

STEP 5

결과 검증·보안

근거 일치도·신뢰도·개인정보·보안 등급을 확인하고 필요한 보완을 요청

STEP 6

문서·승인·내보내기

공식 문서와 분석 결과를 만들고 담당자 검토·승인 후 업무 시스템으로 전달

중간 결과 자동 전달앞 단계의 OCR·조회·분석 결과를 다음 에이전트가 이어받아 재입력 없이 처리
권한·보안 등급 유지사용자의 열람 범위와 문서 보안 등급을 검색부터 결과물까지 일관되게 적용

자료 유형에 맞는 처리 방식 비정형 문서, 구조화 데이터, 복합 업무를 각각 알맞은 도구와 에이전트로 연결합니다.

문서·규정 · RAG

사내 문서와 규정에서 의미가 가까운 근거를 찾아 결합하고 출처와 보안 등급을 함께 제시

표·수치 · Text2SQL

자연어 질문을 데이터베이스 조회로 바꿔 직접 집계하고 표·차트·조회 조건으로 결과를 설명

복합 업무 · Multi-Agent

OCR·주소 표준화·DB 조회·분석·보고서처럼 여러 단계를 연결해 하나의 결과물로 완성

Prototype Workflows

전문 에이전트가 역할을 나눠 결과를 완성합니다

프로토타입은 서로 다른 전문 기능을 순서대로 연결해 사람이 검토할 수 있는 업무 결과물을 만드는 흐름을 보여줍니다.

서류 심사 · 이의신청

이의신청 서류 일괄 처리

입력 스캔 문서와 첨부 자료를 한 번에 접수

연계 OCR → 주소 표준화 → DB 조회 → 관련 규정 검색

산출물 확인 근거와 검토 항목을 담은 심사 보고서 초안

데이터 검증 · 규정 검토

이상거래 검증 보고서

입력 거래 조건과 확인 대상 데이터를 지정

연계 DB 조회 → 데이터 분석 → 내규·법령 검색 → 보고서 작성

산출물 이상 징후, 판단 근거, 후속 확인 항목을 정리한 검토 문서

Ideal Use Cases

이런 상황에서 효과가 큽니다

문서·데이터·규정이 함께 얽혀 있고, 결과물의 근거와 운영 통제가 필요한 업무에 적합합니다.

문서가 많고 형식이 제각각인 업무

보호 문서와 스캔본, 음성 기록을 문자 인식(OCR)과 음성 인식(STT)으로 정리해 검색·요약·검토해야 하는 환경

규정과 근거를 함께 확인해야 하는 업무

내규·법령·지침을 찾아 출처를 남기고 문서 내용과 대조하는 사전 검토·심사 업무

데이터 조회와 분석이 반복되는 조직

데이터베이스와 Excel·CSV를 자연어로 조회하고 통계·이상 탐지·차트까지 만들어야 하는 업무

여러 단계를 사람이 옮겨 적는 복합 업무

문자 인식·주소 표준화·데이터 조회·규정 검색·보고서 작성을 여러 AI 에이전트의 업무 흐름으로 연결해야 하는 과정

결과물을 공식 문서로 남겨야 하는 업무

분석과 근거를 정해진 양식의 보고서·회의록·검토서로 만들고 담당자 승인을 거쳐야 하는 조직

외부 반출이 제한되고 통제가 필요한 환경

사내 소형 언어모델(sLLM)과 지식베이스를 사용하고 접근 권한·보안 등급·이용 기록을 일관되게 관리해야 하는 조직
