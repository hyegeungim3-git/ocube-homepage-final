EVCP

국제 충전 통신 표준(OCPP)을 지원하는 충전기를 한 화면에서 관제합니다.회원·결제를 마이크로서비스로 구성하고, 로밍은 단계적으로 확장합니다.

개요핵심 기능서비스 구조레퍼런스
Overview

충전 사업에 필요한 운영 기능을 한 플랫폼으로 제공합니다

EVCP는 OCPP 호환 충전기를 연결하고 회원·결제·관제를 함께 운영하는 전기차 충전 플랫폼입니다. 충전 사업 구축·운영 경험을 바탕으로 구성했습니다.

국제 충전 통신 표준(OCPP)OCPP 호환 충전기 연동 — 서로 다른 충전 인프라를 한 화면에서 관제
지도 기반 관제다거점 충전소의 상태·이용률·장애 모니터링
마이크로서비스 구조(MSA)회원·결제·연동·관제 독립 확장 — 사업 규모에 따라 유연 확장
Operations Console

운영자가 실제로 보는 화면

충전소·충전기 상태를 지도 기반 그래픽 화면으로 보여주고, 충전 관련 상세 정보를 한 화면에서 확인할 수 있게 구성합니다.

Monitoring

충전소 관제

지도 기반의 운영 충전소·충전기 정보를 그래픽 화면으로 보여주고, 충전 관련 상세 정보를 한눈에 볼 수 있는 화면을 제공합니다.

  • 사업자·지역별 선택 사업자별·지역별 목록에서 운영 충전소를 선택할 수 있습니다.
  • 충전기별 상태·이력 충전기별 상태 정보와 최신 이력 정보를 한 화면에서 볼 수 있습니다.
  • 지도에서 직접 선택 지도 기반으로 충전소를 직접 선택할 수 있습니다.

EVCP — 지도 기반 충전소 관제 (자체 제품)

Dashboard

다이나믹 대시보드

원하는 차트만 선별적으로 표시할 수 있고, 충전기에서 전달되는 상태 정보를 실시간으로 표시합니다.

  • 월별 매출 기간별 매출 추이를 차트로 확인합니다.
  • 충전량 통계 월별 충전량을 집계해 운영 규모를 파악합니다.
  • 가동 충전기 수 지역별로 충전가능·충전중·통신오류·고장 상태를 나눠 집계합니다.

다이나믹 대시보드 — 월별 매출 · 충전량 · 가동 충전기 수

Event

실시간 이벤트 관제

충전기 상태 이벤트를 실시간으로 수집해 목록과 지도에 함께 표시하고, 상태 변경 시각까지 추적합니다.

  • 이벤트 실시간 표시 충전 시작·대기·연결 해제 등 상태 변경을 발생 순서대로 남깁니다.
  • 지도 기반 위치 확인 이벤트가 발생한 충전소 위치를 지도에서 함께 확인합니다.
  • 상태 변경 이력 추적 충전기 아이디·충전소명·변경 시각을 함께 기록합니다.

실시간 이벤트 관제 — 충전기 상태 이벤트 지도 기반 표시

Search

지도 기반 충전소 검색

공공 로밍을 체결한 충전사업자의 충전소·충전기 상세 정보를 지도에서 보여주며, 사용자 앱과 관리자 앱에서 같은 모듈을 활용합니다.

  • 충전소·충전기 상세 지도 기반으로 충전소와 충전기 상세 정보를 제공합니다.
  • 주소 기반 검색 주소로 충전소를 찾을 수 있는 검색 기능을 제공합니다.
  • 운영기관·종류별 필터 운영기관과 충전기 종류(완속·급속·초급속)별로 필터링합니다.

지도 기반 충전소 검색 — 사용자 앱·관리자 앱 공용 모듈

Service Architecture

서비스가 분리돼 장애 대응이 원활합니다

회원관리·충전기 연동(OCPP)·결제·로밍을 각각 독립된 서비스로 나눈 마이크로서비스 구조(MSA)입니다. 한 서비스의 장애가 전체로 번지지 않고, 사업 범위에 맞춰 필요한 기능부터 조합해 확장할 수 있습니다.

👤

회원관리

가입·인증·요금제·이용 이력을 독립 서비스로 운영합니다.

🔌

충전기 연동(OCPP)

충전기별 OCPP 버전과 호환성을 확인해 게이트웨이로 연동합니다.

💳

결제

충전 세션 단위 과금·정산과 결제대행(PG) 연동을 처리합니다.

🔗

로밍

사업자 간 충전 로밍으로 이용 가능한 충전소 범위를 넓힙니다.
