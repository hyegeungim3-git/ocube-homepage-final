Overview

차량 데이터를 운행·에너지·탄소 관리에 활용합니다

Qdrive는 차량에서 운행기록과 진단 신호를 수집해 위험운전, 에너지 사용, 탄소 배출을 함께 관리하는 모빌리티 플랫폼입니다.

OCPP 연계ISO 15118GHG Protocol · ISO 14064LTE Cat M1 자체 모듈

서로 다른 차량·에너지 데이터를 QData의 공통 의미 기준으로 표준화하고, EVCP(OCPP)·Cubeon과 연결해 서비스에 활용하도록 설계합니다.

Data Pipeline

차량 데이터가 서비스가 되기까지

01

수집

커넥티드 차량·충전 인프라에서 주행·에너지 데이터 수집 (OCPP · MQTT · LTE Cat M1)

02

표준화

이기종 데이터를 공통 스키마·온톨로지로 정규화 (QData 표준화층)

03

분석

주행·에너지 패턴 분석 · 충·방전 최적화 · 탄소 저감량 산정

04

서비스

클러스터 UI·앱·관제로 전달 (REST / gRPC API)

Standards & Protocols

표준·프로토콜 기반

모빌리티·충전·탄소 도메인의 통용 표준과 프로토콜을 지원하도록 설계합니다.

OCPP 1.6 / 2.0.1충전 인프라 연계
ISO 15118Plug & Charge · V2G
MQTT커넥티드 텔레메트리
LTE Cat M1차량·충전 통신
REST / gRPC서비스 간 통신
MSAMicroservice Architecture
GHG Protocol / ISO 14064온실가스 산정
TLS 1.2 / 1.3데이터 전송 보안

OCPP는 EVCP에 적용했고, LTE Cat M1은 자체 통신 모듈 개발 경험을 보유합니다. ISO 15118과 GHG Protocol은 사업 요건에 따라 적용 범위를 정합니다.
