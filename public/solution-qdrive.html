Qdrive

운행기록과 차량 진단 신호를 표준 형식으로 수집합니다.위험운전 판정부터 탄소 배출 산정까지 하나의 흐름으로 연결합니다.

개요핵심 기능표준스펙도입효과
Overview

차량 데이터를 운행·에너지·탄소 관리에 활용합니다

Qdrive는 차량에서 운행기록과 진단 신호를 수집해 위험운전, 에너지 사용, 탄소 배출을 함께 관리하는 모빌리티 플랫폼입니다.

Features

차량 데이터로 무엇을 보는가

운행 관제부터 탄소·연료 절감, 성과 검증, 운수사 운영까지 실증 데모 화면으로 확인할 수 있습니다.

Fleet

운행 중인 차량을 한 화면에서

차량 위치와 운행 상태를 지도에 모아 보여주고, 위험운전이 잦은 구간과 연료·안전 지표를 같은 화면에서 확인합니다.

  • 실시간 위치·상태 운행 중인 차량의 위치와 상태를 지도에서 확인합니다.
  • 위험운전 히트맵 급가속·급감속·급회전이 잦은 구간을 지도 위에 모아 보여줍니다.
  • 연료·안전 지표 연료 절감과 안전점수를 한 화면에서 함께 비교합니다.

모빌리티 통합 관제 대시보드 — 실증 데모 예시 화면

Carbon

탄소·연료 절감을 수치로

운행기록(DTG)의 주행거리와 연비를 기준으로 배출 절감량을 산정하고, 운전 습관이 연비에 미치는 영향까지 함께 봅니다.

  • 주행·연비 기준 산정 운행기록(DTG)의 주행거리와 연비로 배출 절감량을 계산합니다.
  • 안전운전 ↔ 연비 상관 운전 습관이 연비에 미치는 영향을 지표로 확인합니다.
  • 기간별 추이 개선 효과를 기간 단위로 누적해 보여줍니다.

탄소·연료 절감 분석 — 실증 데모 예시 화면

Verification

도입 효과를 주장 대신 비교로

같은 조건에서 AI를 쓰지 않았을 때와 견주고, 운전 그룹을 나눠 코칭 전후를 비교해 수치의 근거를 남깁니다.

  • 미적용 가정과 비교 같은 조건에서 AI를 적용하지 않았을 때와 견주어 효과를 확인합니다.
  • 그룹별 코칭 효과 운전 그룹을 나눠 코칭 적용 전후를 비교합니다.
  • 교차 검증 차량진단(OBD)과 운행기록(DTG)을 대조해 수치의 근거를 남깁니다.

성과 검증 — AI 미적용 가정과 비교·차량진단(OBD)·운행기록(DTG) 교차검증 · 실증 데모 예시 화면

Operations

차량과 기사 단위로 운영

운행 현황을 차량·기사 단위로 정리하고, 정비 시점 예측과 운행기록 제출까지 하나의 흐름으로 잇습니다.

  • 차량·기사별 현황 운전점수·연료·재차율·배차 간격을 단위별로 정리합니다.
  • 정비 시점 예측 차량진단(OBD)·CAN 신호로 정비 시점과 비용을 미리 가늠합니다.
  • 운행기록 제출 운행기록 자동 제출까지 연결해 반복 업무를 줄입니다.

운수사 관제 — 차량·기사별 운행 현황 · 실증 데모 예시 화면
