QVision

기존 CCTV 인프라를 그대로 활용해 돌발상황과 위험 행동을 검지합니다.현장 요건과 관련 규정에 따라 엣지 단계에서 비식별 처리하도록 구성합니다.

개요핵심 기능TMS돌발검지
Overview

기존 CCTV를 교통·안전 감지 센서로 활용합니다

QVision은 카메라 영상을 분석해 차종과 통행량을 집계하고, 포트홀·돌발상황·작업 위험을 관제 화면에 전달하는 영상 인식 AI입니다.

국책 주관공공안전 AI 국책과제 — 오큐브 주관·KT 수요기관
0개소세이프뱃지 안전관제 실증
0종자동 돌발상황 감지(AID) 항목
Features

딥러닝 기반 정밀 영상 패턴 검출

카메라 영상에서 차종별 교통량을 자동으로 집계하고, 노면 파손을 실시간으로 찾아 관제로 전달합니다.

TMS

실시간 교통량 검출

도로 영상에서 차량을 검지·분류해 차종별 통행량을 자동으로 집계하고 통계로 정리합니다.

  • 차종별 자동 조사 지나는 차량을 종류별로 구분해 통행량을 자동으로 집계합니다.
  • 교차로 방향별 추적 교차로에서 진행 방향별 교통량을 추적해 검출합니다.
  • 고정식·이동식 운용 설치형과 이동형 조사 환경 모두에 맞춰 구성합니다.

TMS — 실시간 교통량 검출

Road Safety

포트홀 실시간 검출

생명을 위협하는 도로 위의 시한폭탄, 포트홀을 영상 인식으로 검출하고 검출 정보를 관제합니다.

  • 높은 검출율 다양한 형태의 포트홀 학습 데이터로 검출율을 높였습니다.
  • 실시간 검출·전송 주행 중 실시간으로 검출하고 검출 정보를 전송하는 시스템입니다.
  • 관제·관리 수집한 검출 정보를 관제하고 관리하는 시스템을 함께 제공합니다.

포트홀 — 실시간 검출 데모 (차량 영상 인식 · 관제 서버)

TMS · Traffic Measurement Solution

차종별 교통량을 자동으로 조사·통계합니다

AI Vision 기술을 이용한 차종별 교통량 자동 조사 시스템입니다.

학습 데이터60만 건 규모의 학습 데이터를 기반으로 검출 정확도를 확보합니다.
차종 구분국토교통부 기준 12차종에 버스를 더해 총 13차종으로 구분합니다.
방향별 추적교차로에서 진행 방향별 교통량을 추적해 검출합니다.
